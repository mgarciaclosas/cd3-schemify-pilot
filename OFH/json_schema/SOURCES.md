## Parse notes and routing scan

- Dictionary: routing scan — no NA-type labels found in the questionnaire codings (searched "not applicable", "n/a", "skip", "not asked", "inapplicable", "legitimate"). The item-missing codes look like -1 and -3 (also -4 and -999); -7 and -10 look substantive. None is a structural-NA code, so routing here rests on the logic file rather than on codes.
- Logic file: routing scan — strong signal, an explicit `show_if` column. 220 rules over 76 distinct gate variables, grouped by identical expression into 173 `waiting` rows in ROUTING.csv (evidence `quoted`, none encoded). Largest gates: DEMOG_SEX_2_1 (28 dependents), SMOKE_TOBACCO_TYPE_1_M (22), the sibling-count gates (19 each), the parent/sibling diagnosis gates (18 each).
- Cross-source mismatches found at survey: (a) DEMOG_SEX_2_1, DEMOG_GENDER_2_1 and DEMOG_ETHNICITY_1_1 are used in the logic file but live in the dictionary's `participant` sheet, not `questionnaire` — those rules cross tables unless the tables are merged. (b) 76 questionnaire-sheet variables have no logic entry, mostly `_1_1` variants of items the logic file shows as `_2_1` (an earlier questionnaire version) plus ID/PID/QUESTIONNAIRE_VERSION/SUBMISSION_DATE. The dictionary evidently spans more than one questionnaire version; the logic file covers one.
- Linked health records (`linked_nhse_health_records`), routing scan: participant_nhs_linked, nhse_eng_canreg_pre1995 and nhse_eng_canpat show no signal (no NA-type labels, no branching column, no questionnaire, no gate-and-detail name pairs); nhse_engwal_deaths, nhse_eng_canreg_treat and nhse_eng_primcare_meds show weak signals only (numbered cause-of-death slots, treatment flags beside detail fields, codes labelled "Unknown / Inapplicable" and "Not applicable") and are registered as proposals (D105-D109); nhse_eng_canreg_pattumour (NA-type labels on the Gleason scores, behaviour, laterality and screening; site-specific staging fields) and nhse_eng_outpat (twelve diagnosis and twenty-four procedure slots) are registered as proposals (D112-D113); nhse_eng_ed (six slot families of twelve) and nhse_eng_inpat (diagnosis, procedure and procedure-date slots) are registered as proposals (D117); nhse_eng_ecds (slot families of 4, 10 and 12; slot-detail pairs; "EPIKEY is present on A&E and APC linked records only") is registered as proposals (D120), completing the linked health records scan. The source's own placeholder values (dates 1800-01-01 and 1801-01-01, the text code Null, 9998, 9999, A&E times 3000 and 4000) are kept as labelled values (D116). The dictionary marks many linked variables as sparse-coded (D111). The dictionary's pre-1995 site code note: "ICD code is dependent upon year of diagnosis". 109 coding lists, 328,832 codes, six of them over 1,000 codes (D101).
- Entities are provisional `table` values in VARIABLES.csv, taken from the source's own entity column; the interview (Q2) decides the real tables. `category` is `unassigned` until the proposal.
